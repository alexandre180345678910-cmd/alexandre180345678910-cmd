### Perfil

Desenvolvedor full-stack com foco em produtos SaaS em produção. Atuo em todo o ciclo de software: modelagem de dados, APIs, interface, infraestrutura, observabilidade e integração com meios de pagamento. Responsável pelo desenvolvimento do **MacroTracker**, plataforma de estudos para ENEM e vestibulares, conduzindo arquitetura, segurança e entrega contínua.

### Competências

| Área | Atuação |

### Projeto atual

**MacroTracker**: plataforma SaaS de preparação para vestibulares.

- Banco de questões e simulados construídos a partir de provas oficiais (ENEM, Fuvest, Unicamp)
- Planejamento de estudos com cronograma e acompanhamento de desempenho
- Correção de gabarito por fotografia, com OCR executado no próprio dispositivo
- Laboratórios interativos de Física, Química e Biologia
- Módulo de mentoria para acompanhamento de alunos por organização
