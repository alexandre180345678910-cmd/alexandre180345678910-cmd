## Sobre mim

Desenvolvo produtos web de ponta a ponta: do banco de dados à interface, passando por infraestrutura, observabilidade e pagamentos. Hoje dedico meu tempo ao **MacroTracker**, uma plataforma de estudos para vestibulares.

- 🛠️ Construindo agora: [MacroTracker](https://macrotracker.com.br)
- 🧪 Gosto de testar a fundo: unidade, integração com banco real e ponta a ponta
- 🔒 Levo segurança a sério: RLS no Postgres, autenticação e revisão de dependências
- 🤖 Uso agentes de IA no dia a dia de engenharia, com revisão humana em cada entrega

## O que estou construindo

<table>
<tr>
<td width="50%" valign="top">

### 📚 MacroTracker

Plataforma de estudos para ENEM e vestibulares (Fuvest, Unicamp).

- Banco de questões e simulados com provas oficiais
- Cronograma de estudos e acompanhamento de desempenho
- Leitura de gabarito por foto, com OCR no próprio navegador
- Laboratórios interativos de Física, Química e Biologia
- Painel de mentoria para acompanhar alunos

</td>
<td width="50%" valign="top">

### ⚙️ Por baixo do capô

- **App:** Next.js 16, React, TypeScript, Tailwind
- **Dados:** Postgres (Supabase), Drizzle ORM, Row Level Security
- **Auth e pagamentos:** Clerk, Asaas
- **Infra:** Vercel, Cloudflare Workers
- **Qualidade:** Vitest, Playwright, Sentry, CI no GitHub Actions

</td>
</tr>
